# DaClassicLady's Solo Dolo Car Club website

Static site: one `index.html` page plus the `img/` photo folder. No build step.

## Files
- `index.html` — the whole site
- `img/` — cropped photos of the 64 Dodge Custom 880 and car shows (metadata stripped)

## Change the videos
Open `index.html`, scroll to the bottom, and edit the `VIDEOS` (wide, full-length) and
`SHORTS` (tall) lists. The ID is the part of the YouTube link after `youtu.be/` or `/shorts/`.
